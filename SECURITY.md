# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | Currently active |

## Reporting a Vulnerability

We take security vulnerabilities seriously.

If you discover a security issue, please report it responsibly:

### For Bug Bounty Programs
If the target is part of a bug bounty program, follow their disclosure policy.

### For Security Researchers
1. **Do not** create public GitHub issues for security vulnerabilities
2. Send a detailed report to the maintainers
3. Include:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested remediation (if any)

### What to Expect
- Acknowledgment within 48 hours
- Regular updates on remediation progress
- Credit in the security advisory (if desired)

### Scope
- Vulnerabilities in Sniffixx code
- Security misconfigurations introduced by Sniffixx
- Dependency vulnerabilities (report upstream as well)

### Out of Scope
- Social engineering attacks
- Physical security
- Denial of service attacks on third-party services
- Issues related to user misconfiguration
